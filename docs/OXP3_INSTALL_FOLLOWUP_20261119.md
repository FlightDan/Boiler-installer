# OXP3 安装后的语言、指纹和休眠（2026-11-19）

手动和自动选择的系统语言均由通用预设事务写入 A/B 槽。安装器核对两个槽位报告相同语言，并在完成页显示实际值。若自动选择缺少镜像语言资源，完成页显示英语回退。Steam 游戏模式语言由 Steam 设置，较新的 SteamOS 桌面也会跟随该设置。[Valve 的 SteamOS 发行说明](https://store.steampowered.com/news/posts/?enddate=1781730638&feed=steam_community_announcements)

两份 ONEXPLAYER TOON 都申请 `boiler:s2s4`。旧候选的 TOON 明确指定不勾选，安装器据此留空。更新后的两份 TOON 默认勾选该插件，并保留 Decky 依赖和用户取消选择。插件启动后继续使用系统待机策略，用户从插件内启用 S4 时才准备休眠交换文件。

旧品牌包安装 Fingerprint Unlock `0.1.8`，该版本的 Decky 页面仅展示录入指引。适配分支将四个桥接文件和来源锁更新至已发布的 `v0.1.10`。构建时保留原有原生运行时和机型规则，重新校验桥接文件和许可证。独立指纹安装器有自己的安装契约，Boiler 管理的 Decky 使用机型包维护事务。[Fingerprint Unlock v0.1.10](https://github.com/FlightDan/FingerprintUnlock-SteamOS/releases/tag/v0.1.10)

以旧版安装器生成的镜像如仍在原安装会话中，可从对应版本继续写盘。新安装器为新准备镜像生成自己的语言选择与桥接回执。早期手动语言镜像中的旧机型回执保留原始选择。
