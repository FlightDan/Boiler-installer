# Boiler Installer 0.2.4 · SteamOS 启动分区删除

本地 ONEXPLAYER build.2 的包内版本为 `0.2.4-preview.20261114.2`，对应源码 `8a6aa28d729770e5ae851b19b9f736cae170969f`。该包仍要求启动分区匹配预设 GPT 类型、固定尺寸、零属性以及特定 SteamOS/rEFInd 文件。11 月 13 日的识别修复尚未进入该构建。

安装位置页面现在按 GPT 角色名和连续布局识别完整八分区组，或仅剩 `esp / efi-A / efi-B` 的三分区组。Windows 端使用同一删除策略刷新列表并执行管理员预检。删除前后核对磁盘标识、分区 GUID、范围、类型和当前布局。EFI 类型的 SteamOS 槽位也可以通过预检，Windows 当前使用的系统分区、宿主文件卷、无法检查的卷及含其他系统引导文件的卷仍受保护。批量操作继续要求明确确认，逐项删除，失败即停。

启动卷可以为空，也可保留同卷 SteamOS 或项目 rEFInd 的回退加载器，无需固定的 SteamOS 配置文件或 rEFInd 日志。独立或字节不匹配的 `BOOTX64.EFI`、未知 EFI 加载器及共享引导配置仍会阻止删除。本记录反映实际交付策略。

## 构建身份与验收范围

- GitHub `v0.2.4` 的 Windows 交付物为 `boiler-installer-0.2.4-win-x64-slim.zip`。它包含固定提交的适配目录和通用维护运行时，机型包从其独立渠道获取。
- 本地 `build.3` 采用同一安装器源码提交和版本，内置单份经过校验的 ONEXPLAYER `2026.11.14.2` 双机型品牌载荷。品牌版本及其本地测试来源 `df836fd789f8223a108562eda45dd982aab986ef` 沿用 build.2，安装器的公开目录使用已公开的 `caad498e8552762abbf77afdc130a0238e4ed571`。两个机型独立离线导入，通用维护运行时没有预放机型载荷。
- 通用维护版本提升到 `0.2.0+maintenance.22`，用于区分本次已变动的维护及协议文件。安装包带通用运行时，独立签名更新索引沿用原有发布渠道。
- 合成回归覆盖 GPT 类型与属性差异、实时身份变化拒绝、Windows 系统分区保护以及批量删除的预检和停止行为。Windows 测试 VHD 验证了三个卷的原生只读检查及实际删除，其中 `esp` 使用 EFI 类型。生产 helper 的受支持总线端到端验收、已安装系统升级/恢复和用户物理磁盘验收仍待验证。
- 本机准备和工作目录必须选择 RAID。发布附件校验值、已执行的 CLI 检查和本地 build.3 验证记录随交付保存。
