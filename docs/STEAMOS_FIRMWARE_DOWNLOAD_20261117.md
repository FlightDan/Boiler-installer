# 通用安装的固件下载失败（2026-11-17）

0.2.4 的现场日志在完成 SteamOS 3.10 镜像准备后，停于 32% 的组件阶段（步骤 `02.01`）。安装计划为 A/B 槽选中了 Intel、Realtek 和 MediaTek 的六项 Wi-Fi／蓝牙适配。Windows 的下载进程在依次访问 GitLab 镜像和 Google Gitiles 原站时均遇到 `[Errno 11001] getaddrinfo failed`。会话未进入物理盘写入步骤。该日志没有记录 CPU 型号或 SteamOS 实机启动结果。

两个固定来源都无法获取所需文件时，安装器显示固件下载失败、来源主机名和重试办法，并在日志中保留出错文件和原始异常。用户可以恢复网络后按原选择重试，也可以返回取消不需要的额外固件再安装。需要的固件仍必须按既有锁校验并完整准备后才进入后续步骤。

- 源码与模拟回归通过。在原代码上复现两个 DNS 错误未给出来源和文件信息。修订后验证失败信号、临时载荷清理、备用来源成功及空选项免下载。三个需要 Linux 权限或文件语义的既有用例在 Windows 跳过。
- Windows Release 本地编译通过。无线选项、机型目录和 `boiler-checks` 通过。界面截图和真实网络上的安装流程未做验收。
- 维护、升级与恢复无需迁移。失败发生在发布完整私有组件载荷之前，沿用既有载荷和恢复格式。
- 本次仅修改源码并构建验证。未制作发布包，公开下载和 258V 实机验收待带修订的安装器可用后进行。

## 2026-11-18 提示与国内镜像核查

通用构件选择页面新增醒目的联网提示，放在可折叠设置之外。提示说明 Wi-Fi、蓝牙和核显的缺失固件下载来源、国内网络可能无法访问、失败会中止安装，以及检查 Windows 网络、DNS 或代理后重试的办法。机型包或本地镜像模式隐藏该通用按需下载提示。

清华 TUNA 官方文档提供 linux-firmware Git 镜像，本机已通过只读 `git ls-remote` 验证该仓库可连接。官方文档列出 Git 克隆与 remote 用法，未说明可供当前逐文件 HTTP 下载流程直接替换的端点。当前锁定提交和全部固件文件在该镜像的可用性仍需验证，安装器继续使用已有固定下载源。

镜像说明见 https://mirrors.tuna.tsinghua.edu.cn/help/linux-firmware.git/ 。
