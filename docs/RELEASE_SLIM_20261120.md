# Boiler Installer 0.2.7 slim 预览版

本次交付使用 Win x64 slim 包，内置通用维护运行时 `0.2.0+maintenance.34`。机型目录按权威适配提交生成，机型包和签名维护更新索引继续使用各自的分发入口。

- AMD 微码安装兼容 SteamOS 原版的零链接 newc 条目。Intel 和 AMD 微码、12 个核显固件配置、保留维护运行时的虚拟机安装与恢复记录见 [固件虚拟机验收](FIRMWARE_VM_20261119.md)。
- OXP3 和 X2 Mini 的 Intel Panther Lake 机型微码读取 TOON 选择并进入共用早期启动事务。OXP3 实机 B 槽重启确认早期更新到 `0x11d`，其余硬件范围见 [机型微码验收](ONEXPLAYER_MICROCODE_20261119.md)。
- 自定义安装完善语言选择、构件回执、Windows 硬件识别和 SteamOS 分区选择与删除确认。实际物理设备操作由原有权限与目标校验约束。
- 新 TOON 校验器和历史来源检查入口共用同一条默认选择规则。OXP3 和 X2 Mini 按 TOON 默认勾选 S2/S4，其他来源、依赖和许可证约束继续由对应校验步骤执行。

历史本地 ONEXPLAYER 品牌候选仍以各自的验收记录为准。已有签名机型目录及其附件版本沿用原发布。物理 AMD 微码、GPU 驱动加载、指纹录入和 S4 唤醒分别验收。

按现有 unsigned preview 边界，从清洁、精确的公开源码检查构建和 slim 内容，并单独保留维护候选测试、公开下载校验与硬件证据。本机准备和工作文件使用 RAID。
