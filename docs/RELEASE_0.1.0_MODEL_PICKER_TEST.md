# 0.1.0-preview — OXP3 机型列表修正测试包

2026-10-29。本地测试，不推送源码、Tag 或 Release。

Windows 安装器此前将固定机型指南和签名机型目录直接追加到同一个下拉框，
导致 `device:oxp3` 以 ONEXPLAYER 3 显示两次。现在按机型 ID 合并为一项。
新选择优先使用随包测试适配；没有随包适配时使用未撤销的签名包，
均不存在时仅提供指南。多版本签名记录沿用目录顺序，不自行推断版本排序。

目录异步载入或刷新时保留用户明确选用的有效可执行来源。仅有指南的选择
可以转为同机型的签名包候选，同时刷新详情；这不会授予信任或加入安装方案。
撤销记录继续生效，机型 ID 合并不代替摘要校验和用户确认。

Linux 通用维护器已按机型 ID 显示单项，本次无需修改。安装脚本、组件清单、
依赖、默认选择、OXP3 `.6` 设备载荷和维护器 `.4` 均未改变。
保留 Opti2XMX 0.3.0 和三份 OptiScaler 离线归档，不重跑长虚拟机流程。
