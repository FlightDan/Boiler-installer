# Boiler Installer 0.1.0 测试构建：2026-10-30

本次测试版用于验收安装容量、Windows 临时空间和便携启动行为。

- SteamOS 安装默认选择 128 GiB，仅允许 128 或 256 GiB；不再提供自定义容量。系统与启动分区约 24.375 GiB，其余分配给 home，格式化前分别约 103.625 和 231.625 GiB。
- 复制稀疏 IMG 和流式导入镜像时跳过零数据，保留逻辑长度及内容；稀疏源的工作空间预估使用实际数据范围。普通非稀疏 IMG 保留保守预估，各写入阶段继续检查剩余空间。ZIP/BZ2 的展开空间通过实际写入检查，不能从压缩大小推断实际数据量。
- 安装界面默认勾选“安装成功后清理临时文件（保留下载缓存和日志）”。成功写入及读回核对后，清理该任务的来源快照、准备镜像、官方系统展开副本、虚拟准备盘和载荷传输副本；下载缓存、任务日志及分区记录保留。失败、中断或仍在运行的任务保留恢复文件。锁定文件的清理失败会明确报告；重启前再次尝试清理。
- 根目录的 BoilerInstaller.exe 使用包内 .NET Desktop Runtime，无须用户安装系统运行库；开发目录的启动入口同样改为使用自带环境。必须解压完整 ZIP 并保留其目录结构。
- 设备修复选项默认收起；小窗口压缩重复标题说明，保留可滚动内容区。更新旧界面测试场景，验证当前通用组件与机型组件的边界。

此包保留上一候选的 Opti2XMX 0.3.2-dev.1、电源组件 0.2.2 和麦克风修复，模型载荷内容与版本不变。保留维护器版本为 0.1.0+maintenance.9。新增行为属于 Windows 安装器，无须改动已安装设备的维护载荷。

测试发布使用新的时间戳构建及精确源码提交，属于非 Latest 的预发布；包含明确标记的本地测试机型包，不视作正式设备注册表或维护升级目录。源码检查、Windows 构建、真实稀疏文件与离线 GPT/ext4 测试、界面渲染以及最终包内清单分别验收，最终结果见对应 Release 记录。

本次不代表实机首次启动、触摸硬件、双启动恢复或 S4 休眠通过；已有掌机的 home 不会随安装器更新自动扩容。
