# 安装确认流程调整 · 2026-11-19

- 在「系统来源」确认本地镜像或升级源时，只做来源格式和文件身份检查，点击「下一步」即可选择安装位置。移除 MD5 计算、进度和跳过按钮。点击「开始安装」后获取 SHA‑256，安装控制器将它与从受保护读取句柄复制的暂存镜像比对。该比对用于发现文件替换或变化。官方缓存与 Boiler 镜像包原有的完整性校验继续执行。
- 「确认方案」显示「使用虚拟化加速」。WHPX 可用时默认勾选，取消后当前安装及管理员助手的虚拟机检查均使用 TCG。WHPX 不可用时，点击该选项会显示 Windows 虚拟机监控程序平台的启用操作。启用后可立即重启到 Windows，UEFI 一次性启动项指向 Windows Boot Manager。
- 选定机型包后隐藏安装选项中的「识别当前电脑硬件」。切回通用配置即可重新使用。首页和向导的语言选择前显示地球和字母图标。
