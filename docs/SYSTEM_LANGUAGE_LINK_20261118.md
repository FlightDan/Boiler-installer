# Windows 与 SteamOS 默认语言联动（2026-11-18）

安装器启动时读取 Windows 显示语言。安装器界面按自身支持的语言匹配，缺少匹配时使用英语。系统与桌面语言的“自动”选项优先使用 Windows 原始语言及其地区，例如 `pt_BR` 或 `fr_CA`。中文区域和书写变体沿用简繁映射。手动切换右上角界面语言会更新自动选项，单独指定的目标语言和“保持镜像语言”选择会保留。

安装准备按目标镜像检查 UTF-8 locale 和 KDE 翻译。自动选项缺少语言资源时使用经过相同检查的 `en_US`，并把实际语言记录到安装结果。SteamOS 系统区域和 KDE 桌面配置由同一事务写入和恢复。损坏的资源及用户家目录中的冲突设置仍按现有规则处理。Steam 客户端使用独立的语言设置。[Steam 语言设置](https://help.steampowered.com/en/faqs/view/4984-C127-121D-B3F2)

已保存的手动方案继续按原格式读取。自动选择标记随新方案进入审核、部署和只读复核。机型旧版桥接器在自动方案使用 `system`，由通用预设事务负责目标语言。直接刷入已有 IMG 继续保留镜像语言。
