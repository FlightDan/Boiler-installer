## 安装、维护与恢复

Windows 使用现有机型包导入和静态组件选择入口；OXP3 Battery 在原 `charging` 选项中。Linux 维护运行时修订 `0.1.0+maintenance.5`，机型菜单新增“Battery 0.2 / 麦克风修复”视图。OXP3 原机型选项入口继续管理原适配，新增视图管理麦克风；X2 新视图管理两个静态组件。两份本地机型缓存同步给 Linux 维护载荷。

静态组件复用 Engine 文件事务、原始文件备份、验证和恢复；每个组件单独提交，不将多组件操作声称为整体原子操作。恢复会拒绝外部更改的目标文件。安装前、等待锁后均核对计划的根目录、环境、现有状态和目标快照。首次组件提交前中断也保留恢复入口；系统升级后仍可验证和恢复已安装事务。会话服务与插件更改需要重新登录/重启后生效。

麦克风即时实机修复已由主控完成：四次原生 mute/unmute 均约 0.1 秒内对应 Capture off/on；桥接服务与 WirePlumber 重启后约 0.4 秒内恢复同步，用户默认 target 的 Wants 已挂接。源音量保留 `85196/85196`（130%）、Capture Vol 38、Boost 0；系统根只读状态恢复 enabled。实机脚本 SHA-256 为 `25074a70432dcd3be14f48b5e3133f063611ad0fd46805fbfa829c054b03c269`，与最终两包相同。未执行真实操作系统重启或待机/休眠；X2 未做实机验收。
