# 界面语言与自动匹配（2026-11-18）

Windows 安装器和 SteamOS 维护器支持简体中文、繁体中文、英语、日语、韩语、德语、法语和西班牙语。Windows 首页和安装向导、SteamOS GTK 维护窗口均可从右上角切换语言。KDialog 维护菜单也提供语言切换。每次启动按 Windows 显示语言或 SteamOS Plasma 显示语言匹配，SteamOS 可从会话区域设置取得语言。地区和中文书写变体映射到可用的界面语言，未匹配的系统语言和缺少译文的条目回退到英语。

安装方案继续分别记录界面语言和目标 SteamOS 桌面语言。切换界面语言保留显式桌面语言、构件选择和启动器选项。旧版机型维护脚本按已锁定的两种语言接收选项，六种新增语言通过旧版接口时使用英语，目标桌面语言仍沿用已核验的选项。原有方案及维护回执格式继续使用。

## 验证范围

- Windows Release 编译通过。选项回归测试逐项验证了新增六种语言、地区变体、英语回退和已选配置。首页和向导布局回归通过，核看了实际渲染的截图。
- `boiler-checks` 和 `model-catalog-checks` 通过，使用模拟镜像和机型选择。目标桌面语言与旧版构件接口的 Python 回归通过，Windows 跳过需要 Linux 文件语义的用例。
- 从源码重新生成并验证了通用维护载荷。核对了语言模块、八种桌面入口名称及清单中每个实际载荷文件的大小与 SHA-256。维护包复现、独立引导包与模拟升级回归通过。
- Windows 首轮全量 Python 回归运行 1,054 项，出现 3 项断言失败、17 项错误与 98 项跳过。显卡证据 URL 相关的显卡目录、下载、固件和安装集成测试分别复测通过。缓存暂存测试写入夹具时报错，仍待复测。独立触控回归套件在创建配置到 RAID 的测试目录时遇到访问拒绝。
- SteamOS 实机界面、在役版本升级与恢复验收待做。发布包、签名和公开下载属于后续发布验证。
