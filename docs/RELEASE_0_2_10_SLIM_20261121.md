# Boiler Installer 0.2.10 slim source integration

This source candidate starts at public installer commit 57add9300ab31ad76acc9ddf513cd7ceb78697eb and keeps its locked public adaptation snapshot. It integrates installer partition and startup handling, model selection behavior, Steam language and offline DNS preparation, and retained-maintenance compatibility from the local 0.2.10 candidate. Generic maintenance is version 0.2.0+maintenance.41. The local brand builder and private model snapshot are not included.

## Delivery gates

- Source integration: candidate only; independent review and source tests are pending.
- Maintenance build and upgrade/recovery: pending; prepare and verify before the installer.
- Windows build and packaged installer checks: pending.
- Release packaging, signing, publication and downloaded artifact verification: pending. Release attachments must be slim and contain no model packages.
- Physical-device installation, first boot, network changes and operating-system update: pending.
- Dual-model brand package and physical-device acceptance: not established by this source candidate.

The DNS baseline is applied during offline image preparation. Existing custom DNS is preserved by refusing unsupported preparation; rebuilding from verified official source is the recovery path. Steam language seeding is conditional on recognizing the launcher and a fresh user registry. Actual image and device behavior require separate acceptance.
