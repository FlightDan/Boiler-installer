# 0.1.0-preview 本地触屏修正，2026-10-29

本次修改 Windows Boiler 安装器的系统来源、机型适配、通用安装及启动设置界面。
沿用 0.1.0-preview 显示版本，使用新的 TouchFixQa 本地应用构建，不覆盖历史公开附件。

- 系统来源页点击下一步改为单次顺序读取文件，计算并显示 MD5；显示实际百分比、
  已读大小和速度，可取消。不再复制、解压镜像或启动虚拟机检查版本、分区和内核。
  同次读取计算原安装协议所需的 SHA-256，供执行时绑定已选文件。没有参考 MD5 时明确
  显示未核对匹配，不把计算摘要说成来源真实性验证。实际安装准备阶段的结构、系统版本、
  内核及官方升级源检查保留，并在物理写入前执行。
- OXP3 旧适配选项与普通机型包一致，所有可用项目默认勾选，依赖一起选择，不可用项
  保持禁用。选择机型包 Decky 会取消通用 Decky；手动切回通用 Decky 时取消依赖它的
  机型包项目。重新选择同一包保留手动选择。
- 机型按钮统一为“使用所选机型包”，删除主流程中的“随包测试适配”“本地测试适配”
  重复提示。实际包的摘要、校验和信任合约不变；手动导入外部包的来源确认保留。
- 打开机型下拉列表不自动激活搜索输入框；点击输入框仍可搜索。核显下拉现有行为不变。
- Vanilla / 通用入口直接进入系统来源，无需再选择机型；自定义页的通用安装按钮也直达
  系统来源，清除先前机型包选择。
- 启动设置两项主勾选文字为 18px，缩短说明、将备份/BitLocker/操作细节收起到
  “启动说明”，菜单等待设置放在主要选项范围内。
- 更新选项默认勾选，主文案为“为保留适配，暂停安装后进入系统时的首次更新”。
  说明提示准确记录现有策略会持续暂停系统镜像更新，直到恢复策略；未新增自动解除行为。
