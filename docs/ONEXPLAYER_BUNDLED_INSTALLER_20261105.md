# ONEXPLAYER bundled installer

Open the installer, choose ONEXPLAYER 3 or X2 Mini under Bundled with installer, and continue through the ordinary installation flow. The installer includes both model packages. Import local package is available on both model sources.

The executable model configuration selects each available component by default unless its TOON declaration explicitly opts out. This includes the shared Intel BE201 resource on both models. Component selections can be adjusted. Existing target checks still apply to conditional repairs. The installer uses the same component transactions for writing and restoring files.

This is a local candidate for hardware testing. The Windows installer and the retained maintenance runtime contain the same pinned model packages. Public slim builds use the separate download path.
