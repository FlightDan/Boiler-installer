## 本次源码变更

- 每个机型使用各自的 TOON 源文件；生成总 TOON 索引及兼容运行时的 JSON 视图。品牌共用组件可由机型引用，构建器读取机型声明，而不是维护第二份手写 JSON 机型模板。
- 官方 TOON Python 解析器固定为 1.2.0，含许可证和字节锁。机型新增后，快照及 Windows、维护器载荷的文件闭包随已校验的清单生成；保留现有签名和显式本地测试信任边界。
- OXP3 可从显式提供、校验过的 .2 基包和锁定输入执行 .2 → .3 → .4 → .8 构建。实际清单与现有 .8 一致；最终 ZIP 的时间戳随构建变化。此前阶段仍需显式提供输入，当前尚不是无外部工件的源码自举。
- X2 候选复用电池休眠、麦克风、游戏模式环境隔离、槽位切换工具和可恢复的 KDE 屏幕键盘配置；电池充电控制不启用。候选明确 `complete: false`，未达到整份机型适配清单的完成标准。
- Windows 机型指南和维护界面提供兼容提示；机型名称不匹配或无法读取时由用户决定继续。系统、运行依赖、事务和恢复检查仍单独适用。尚未接入的上游 X2 HDR 脚本仍有精确机型限制，未来接入前必须改为提示式入口，保留原始上游源码。
