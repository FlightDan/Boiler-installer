# OXP3 实机测试步骤

本包为 2026-10-29 本地测试候选，包含 Windows 所需运行时、QEMU/Linux guest、
通用核心资源、固定机型清单和完整 OXP3 开发适配包。SteamOS 系统镜像由安装器
按官方流程取得，不把系统镜像塞入本包。OXP3 适配资源已随包携带，无需另找设备 ZIP。

1. 将完整 ZIP 解压到一个新目录，运行其中的 `BoilerInstaller.exe`；不要直接从压缩包中启动。
2. 进入自定义安装，在“选择机型”中选 OXP3，点击“使用所选机型包”。
3. 使用安装器的官方 **SteamOS 3.10** 路径。本机型包要求 BUILD_ID `20260924.1000`、
   内核 `7.2.4-valve1-1-neptune-72-g5ab4af5e2eb9`；不符合的镜像会拒绝适配。
4. 全部可用适配默认勾选，可按需取消；依赖会联动选择，不可用项目保持禁用。
   “为保留适配，暂停安装后进入系统时的首次更新”默认勾选。系统镜像更新策略保持暂停，
   直到恢复该策略；应用更新不受影响。机型包 Decky 与通用 Decky 自动二选一，通用维护工具保留。
5. 核对安装概览、语言、目标磁盘和分区后，按现有安装向导完成。不要将未备份的数据盘
   当作测试盘；最终磁盘确认仍由安装器现有流程处理。

进入系统后先记录能否首启和返回 Windows，再测试按键、陀螺仪校准、重启和休眠。
可选 HDR、功耗或其他插件单独测试，不把安装完成视为所有硬件功能验收通过。
本包没有更新旧机维护器或自动迁移旧系统的功能。

出现问题时保留安装器结果页和导出的诊断日志，记录选中了哪些适配、实际 SteamOS
版本/内核、失败阶段以及是否已经写入目标盘。原镜像与测试包保持原样，避免混用旧包文件。

X2 Mini 在本轮可查看指南及未实现原因，尚无随包可执行设备适配；PL4 175W 不可安装。

Opti 同步版另外携带 Opti2XMX 0.3.0、OptiScaler 0.9.4 / 0.7.9 / 10.0.0-pre1_20261025
三个原版离线归档。OXP3 自定义适配默认勾选 Opti2XMX；其 Decky
依赖会切换为机型包版本，与下方通用 Decky 二选一。维护工具继续保留。
FSR 模型仍通过插件的本地导入入口提供；本包不附带该模型或用户游戏配置。

## Linux 通用维护器测试

使用 2026-10-29 Linux 同步版的新 ZIP 完成新装、首启后，进入 KDE 桌面，在应用菜单
搜索“Boiler 维护工具”（Boiler Maintenance）。也可由桌面用户运行
`/usr/local/bin/boiler-maintenance-ui`；不要把整个窗口以 root 用户运行。

1. 选 OXP3，明确同意仅本次信任随包测试适配，并在系统授权窗口确认后端权限。
2. 查看现有安装器配置、适用原因和不可用项。首次安装会核对原安装日志并纳入 Boiler
   的独立维护状态；未接管前不会把安装器配置误报为已由 Boiler 验证。
3. 首轮保留 Linux 可维护的 input、multifunction、gyro、xe-dsb 四项；Windows 新装的
   split-lock 仍保留，但 Linux 通用文件入口不写 EFI，不能在此更改该项。
4. 确认继续保留已有系统更新暂停策略，审阅活动系统槽、PARTUUID、共享目录和变更，
   再确认执行。安装完成表示文件与事务完成，服务激活及硬件效果在重启后另测。
5. 测试“验证已安装适配”。发现校准或配置被外部修改时，应显示差异并保留文件，
   不应把验证失败当作成功。不要为通过验证而覆盖自己的校准数据。
6. 更改已纳管组合前，先明确选择“恢复已安装的适配”，再按新组合安装；回执与原始
   备份保留。中断后使用明确的恢复入口，保留错误和回执，不手工删除私有状态。

本地 CLI 可只读查看同一指南：
`/usr/local/bin/boiler-maintenance --root / models list --offline`。
没有 KDE/KDialog 时使用该 CLI 入口查看帮助；本包不会临时下载安装界面依赖。
接管后的同一批适配使用 Boiler 管理，避免旧维护器和 Boiler 交替修改。
