# ONEXPLAYER TOON resources

The OXP3 and X2 Mini model TOONs select the same Intel BE201 resource. The brand archive keeps one copy of its nine firmware files. Each generated model package lists that resource. Older packages can still be imported.

In a developer session, select the correct model and explicitly choose Intel BE201 in the normal component list for a target known to have BE201. The normal image integration applies the resource in both root slots. It replaces c106 and adds the other files only when missing. Existing compressed alternatives are kept. Use the generic maintenance inventory and verify, restore, or recover commands for the corresponding slot transaction.

The candidate uses the existing developer import. Automatic selection for signed production installation requires a verified hardware match for the physical target. Real Wi-Fi, Bluetooth and physical installation are acceptance checks for the two handhelds.
