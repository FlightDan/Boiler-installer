# 通用维护器 .18 与两机型候选

Boiler Maintenance `0.2.0+maintenance.18` 通过 KDE 应用菜单打开 GTK3 界面。运行中 Linux 的 DMI 与权威 TOON 生成的锁定目录精确匹配。通用维护器和设备包使用各自的签名索引。历史机型仓库仅在目录确认无匹配 TOON 时提供发布提示和指南。Opti2XMX 上游版本与 Boiler 可应用版本分开展示。

下载由桌面用户执行。提权计划和执行将已签名索引复制到私有目录，并在事务前重核机型、兼容性、载荷及所有权。通用维护包只接受正式发布渠道的静态运行时。机型构件和插件须有可验证的所有权及对应维护契约。旧机型适配继续通过各自的固定维护入口验证与恢复。
