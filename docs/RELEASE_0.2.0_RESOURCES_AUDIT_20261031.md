# Boiler 0.2.0-pre.20261031.1 软件检查与审计

本次测试版使用一份共享资源池。ONEXPLAYER 3 与 X2 Mini 引用相同的 30 个资源、相同的默认选择；HDR 参数分别为 472/1100 与 475/700。安装器、首次启动处理器、维护器的检查、经用户确认的恢复及重试入口已接通。独立机型整包不是默认产物，外部资源导入入口保留。

## 资源与来源

- `Boiler-adaptations` 独立保存通用实现、跨品牌硬件资源和逐机型 TOON。G3E 拓扑、公开 CPU 控制和遥测 schema 位于 G3E 目录。声明、清单、锁和人工维护的配置均为 TOON；上游要求的运行时 JSON 由构建器生成。
- 每个资源具有独立来源锁。总索引、源文件闭包和精确 SDK 合同共同校验输入。EC 编译证据也从适配仓库锁定的 TOON 读取，不再隐式读取旧适配目录的 JSON。
- 公开 CPU 代码保持 commit `72f864e0498c10366493c74608c5ffed62cc99ca` 的八个固定载荷。未公开功耗研究代码不在导出、资源池或安装包内。
- Opti 的 137 个安装目标保持原有文件内容、权限和作用域。相同内容在资源池按 SHA-256 仅存一份，消除约 364 MB 重复载荷；不会为两个机型各复制一套资源。DirectX Agility DLL 不随 Boiler 二次分发，显式游戏操作可从锁定的官方原始归档获取并校验。
- Waydroid 的五个项目构建包来自锁定公开源码；两个官方依赖保留原签名。预发布的 unsigned 例外只覆盖显式同意的本地测试和固定五个包，不修改系统 pacman 配置或信任库。

## 审查后修复

- 修复 Decky 资源依赖与安装器 `core:decky` 标识不一致。
- 保留共享 home 两槽持有者、原始配置、用户修改和中断恢复记录；禁止另一未结束操作的标记被覆盖。
- 补齐从未取得叠加层配置所有权、取得过程中退出，以及文件恢复完成后回调失败的继续入口。维护器会重新展示当前恢复计划，确认后继续恢复。
- 修复 Waydroid 活动槽包恢复缺少根分区写入窗口，并覆盖部分卸载失败后的重试。
- 补齐 CPU 同代重装交接、账本归档和旧事务停止证明；同一次启动中旧服务文件已按事务移除后，仍可继续剩余文件恢复。该证明只授权文件恢复，不授权 CPU 控制写入。
- 拦下会回退 CPU、输入、Flathub 和叠加层代码的旧分支合并，按资源逐项合并。
- 修复小窗口侧栏被底部按钮挤压造成的导航和焦点遮挡；移除已完成项目的旧“待实现”展示。

## 桌面 HDR 原生证据

最终 native 归档 SHA-256 为 `9a612934745583aa581a502190b3a32f3d089c6a41ba0caed910f03e13f157a5`，完整对应源码归档为 `4bf7ce54a38a65e06890e593d0f3e69f9aedbc4b2e71c8a0522e489d8dbf1c23`。使用 405 个固定 SDK 包重新验证签名后完成构建，安装前缀与 RPATH 均为 `/opt/oxp3-desktop-gamma22/6.7.3-1.6`。

新 KWin、libkwin、EDID 探针、接口探针和测试图程序在目标 SteamOS 只读环境通过链接和符号检查；新 KWin 版本调用、有效 EDID、原生色域和 HDR 接口查询通过。独立 user-systemd 守护、超时、退出和恢复测试通过。既有 OXP3 游戏 HDR 的 LuaJIT 与实机显示验证继续有效。

这些结果不代替本测试版的完整实机安装、双槽切换、X2 面板显示和外设体验验收。Android 镜像由官方初始化流程按需获取；构建环境中的镜像服务曾返回 403，持久失败与重试已验证，未宣称实际 Android 容器运行通过。

## 发布与使用

这是供用户安装验收的 pre-release。普通正式更新的签名信任没有放宽，也未生成替代签名身份。资源选择仍需明确同意本地测试；机型名称不同仅提示并允许继续，实际系统版本、驱动、接口和依赖检查保留。

GitHub 发布附件和 RAID 测试目录提供完整 Windows ZIP、匹配维护载荷、清单及 SHA-256。包的 `build-info.json` 记录精确安装器源码提交和单份资源池交付；安装器源码中的 `components/locks/boiler-adaptations.toon` 绑定独立适配仓库提交、SDK 及原生归档。请使用发布附件的校验文件核对最终 ZIP；本记录不包含会形成自引用的 ZIP 哈希。

旧工程目录清理已按用户要求推迟，本次交付不以删除旧源码或缓存作为成功条件。
