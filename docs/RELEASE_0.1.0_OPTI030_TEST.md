# 0.1.0-preview — OXP3 Opti 离线测试包

2026-10-29。仅生成本地测试 ZIP，不推送源码、Tag 或 Release。

本轮在已完成机型清单同步的基础上加入已发布 Opti2XMX 0.3.0，以及官方
OptiScaler 0.9.4、0.7.9 和 10.0.0-pre1_20261025 原版 7z。完整归档预置到
插件实际使用的 `downloads/<tag>/<filename>`，选择该适配后可离线准备。
XeSS XMX 运行库仍为已发布 20261005 构建，原始字节不变。

FSR-4.1.2-Lite-XMX-OptiClick-0.6.zip 继续由用户本地导入。本包不包含用户游戏、
私有 FSR 模型、权重、该模型包内的 NVIDIA DLL、生成的内核、设备凭据或研究代码。
公开插件自带的兼容适配器、依赖源码及许可证与官方 ZIP 保持一致。

OXP3 设备包使用 `0.1.0-localtest.20261029.6`，通用维护载荷使用
`0.1.0+maintenance.4`。项目显示版本不变，不修改 README。

Opti 依赖机型包的 Decky。Windows 界面在选择该依赖时取消通用 Decky；明确选择
通用 Decky 时取消机型包 Decky 及依赖它的选项。后端仍拒绝同时部署两种 provider。
已有通用 Decky 的 Linux 系统不自动迁移：Opti 会因 Decky 服务所有权冲突不可选，
具体原因可查看 Decky 行。新装选择机型包 Decky 后，Opti 使用其原有插件目录。

默认五项硬件适配不变。测试 Opti 时，在自定义安装中另外勾选
“Opti2XMX · 每游戏 XMX / Opti 注入与版本管理”，保留维护工具并确认安装概览。
游戏内效果、FSR 本地模型导入及硬件验收由用户实机测试。
