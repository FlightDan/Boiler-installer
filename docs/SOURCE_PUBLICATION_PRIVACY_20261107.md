## Confirmed defects and corrections

- The old string sanitizer left the GPT partition identity inside a Base64 EFI load option unchanged. The sanitizer now parses the retained GPT hard-drive/file-path device path and replaces its little-endian GUID using the same mapping as JSON. Unreviewed device-path forms, malformed entries, or opaque optional data stop fixture generation rather than being silently exported.
- GUID spelling differences (uppercase/lowercase and braces) previously produced different synthetic identities. The mapping now normalizes the UUID before hashing while preserving braces where present.
- The derived partition layout pre-sanitized disk identities and then sanitized them again. It now projects original values and sanitizes once.
- The after-install disk snapshot previously invented unrelated role GUIDs. It now reuses the sanitized role identities from the same installation layout.

Both session fixtures and the derived read-disks fixtures are regenerated by the normal generators from explicit retained private inputs. Manifest sizes and SHA-256 hashes come from final generated bytes, not manual manifest changes. No private original identifier is used as a public regression-test literal.
