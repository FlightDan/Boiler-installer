# Generic model release candidate — 2026-11-04

The existing `--model` candidate flow accepts one or more model packages from the exact committed authority TOON catalog and generated device records. It requires a clean source checkout, source inventory and generated views verified against the exact commit’s Git blobs, the independently signature-verified previous index digest, a monotonic sequence and the existing exact installer commit and package/archive checks. The historical OXP3 and X2 package IDs always retain their existing fingerprint and legacy validation. Other models cannot claim those identities, their device IDs or their OXP3 or X2 Mini model-specific components and selection contract. The `--package` paths remain unchanged.

This produces an unsigned candidate, not a release or a signature. Source-only and synthetic package tests do not establish physical hardware compatibility, installation, maintenance, upgrades, recovery, signed publication or final download acceptance. The imported fingerprint record remains unchanged as historical evidence; the current authoritative source and model-source-files inventory are the current source of truth. A real release requires independently verified inputs, signing and all applicable delivery gates.

Candidate verification executes the model tools from the exact verified Git-blob source bytes. The pinned TOON codec is compiled from its authenticated source bytes, without reusing cached modules or Python bytecode. Regression tests include preloaded fake modules, timestamp-valid forged bytecode, and Git-hidden worktree edits; these are source-validation checks, not signature or device acceptance.

A synthetic generic candidate and a tampered package were also checked with the real protocol from a separate clean Boiler Installer checkout at commit `970c49bf33a5197f2486096e5e155ae55a0830cb`, supplied explicitly to the test. The real validator accepted the original and rejected the changed package bytes. This is not a published artifact, maintenance, recovery, or hardware test.
