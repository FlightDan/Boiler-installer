# X2 Mini FTE3600 local overlay — 2026-11-14

The X2 fingerprint overlay now requires an explicitly supplied kernel module,
locked to the tested kernel and source revision. Its oneshot starts before the
bundled fprintd and checks DMI, kernel, SPI ACPI identity, spidev binding,
spidev buffer size and module bytes before loading the UIO dependency and glue.
The existing shared userspace and OXP3 overlay remain separate.

Acceptance gates:

- Source inventory and generated catalog: checked separately by their normal generators.
- Physical evidence before packaging: module ABI 2 and ready state observed; after restarting fprintd the user completed KDE enrollment and D-Bus reported a template.
- Packaged installation and first boot: pending; the evidence above predates this package.
- Maintenance upgrade and recovery: pending integration and validation.
- Windows build and artifact download: pending; no release is claimed.
- Other X2 kernels and BF63112: no new hardware acceptance; the helper does not load the glue on mismatch.
